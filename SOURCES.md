# Sources / Evidence Record

## Primary research

1. Adrian Kosowski, Przemysław Uznański, Jan Chorowski, Zuzanna Stamirowska, Michał Bartoszkiewicz. **The Dragon Hatchling: The Missing Link between the Transformer and Models of the Brain.** arXiv:2509.26507 (2025). https://arxiv.org/abs/2509.26507
   - Used for: BDH architecture, synaptic-plasticity working memory, sparse positive activations, interpretability claims.

2. Björn Engdahl et al. **BDH-CQ: In-Context Learning with Recurrent Latent Reasoning.** arXiv:2608.09888 (2026). https://arxiv.org/abs/2608.09888
   - Used for: inference-time recurrent-memory updates, latent iterative reasoning, ARC-AGI-1 result.

3. Soham De et al. **Griffin: Mixing Gated Linear Recurrences with Local Attention for Efficient Language Models.** arXiv:2402.19427 (2024). https://arxiv.org/abs/2402.19427

4. Aleksandar Botev et al. **RecurrentGemma: Moving Past Transformers for Efficient Open Language Models.** arXiv:2404.07839 (2024). https://arxiv.org/abs/2404.07839
   - Used for: concrete recurrent language-model deployment context and fixed-sized state.

5. Ali Behrouz, Peilin Zhong, Vahab Mirrokni. **Titans: Learning to Memorize at Test Time.** arXiv:2501.00663 / NeurIPS 2025. https://arxiv.org/abs/2501.00663
   - Used for: learned memory and long-context trade-offs.
